There is a limit _MAX_INT_DIGITS set to 100.
Integers whose absolute value has that many digits or more are rejected.

seal_literal(value, optional _stack):
  Validate value and return an immutable deep copy safe to store on a recipe node.
  _stack tracks object identities currently being visited so cycles like a list containing itself are rejected.
  If _stack is missing, start a new empty stack.
  If value is None, a string, or a bool, give it back as-is.
  If value is an int but not a bool, require it is bounded, then give it back as-is.
  If value is a float, require it is finite, then give it back as-is.
  If value is a mapping, seal it with the cycle guard.
  If value is a list or tuple, seal it with the cycle guard as a tuple of sealed items.
  Otherwise raise a syntax error that symbolic values do not support that type.

seal_mapping(value, optional _stack):
  Seal a dict-like value: string keys only, immutable mapping result.
  If _stack is missing, start a new empty stack.
  Then seal the mapping body with that stack.

literal_as_plain(value):
  Give back a detached plain list/dict copy of a sealed literal for records or display.
  The recipe node keeps its sealed snapshot; this does not change what the AST holds.
  If value is a mapping, rebuild a normal dict with plain children.
  If value is a tuple, rebuild a normal list with plain children.
  Otherwise give value back as-is.

_require_bounded_int(value):
  If abs(value) is at least 10 to the power of _MAX_INT_DIGITS, raise a syntax error that symbolic integers are too large.

_require_finite_float(value):
  If value is not finite, raise a syntax error that symbolic values cannot contain non-finite floats.

_require_string_key(key):
  If key is not a string, raise a syntax error that symbolic value dict keys must be strings.
  Otherwise give key back.

_enter(stack, container):
  Mark container as in-progress on stack.
  If its identity is already on stack, raise a syntax error that symbolic values cannot contain cycles.
  Add the identity to stack and give that identity back.

_seal_mapping_with_cycle_guard(value, stack):
  Enter the mapping on stack.
  Try to seal the mapping body.
  Finally leave so the same object can appear again as a sibling, not as an ancestor.

_seal_sequence_with_cycle_guard(value, stack):
  Enter the sequence on stack.
  Try to seal each item and remember them as a tuple so the sequence cannot be appended to later.
  Finally leave the identity on stack.

_seal_mapping_body(value, stack):
  Build a new dict.
  For each key and item in value:
    Require the key is a string.
    Seal the item with the same stack and store it under that key.
  Give back a read-only mapping view of that dict so item assignment is impossible after sealing.
