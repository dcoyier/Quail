There is a set _ALLOWED_KINDS of None, "source", and "analysis".

Field is an immutable named column or tag reference.
It points at a column header, not at cell values in any row.

A Field remembers:
  name
  kind (default None)
  bound_dataset_id (default None) — set when a binding is saved; not part of equality

After creating a Field:
  Require that name is a non-empty string.
  Require that kind is allowed.
  If bound_dataset_id is set, require a non-empty string.

to_record:
  Give back a plain dictionary of name and kind.
  Include bound_dataset_id only when set.

Equality between two Fields:
  If the other value is not a Field, raise a syntax error that Field comparisons are not supported and values must be compared with Expression(Field(name), Value()).
  Otherwise two Fields are equal when name and kind both match.

Inequality between two Fields:
  The opposite of equality.

Hash of a Field:
  Hash of the pair (name, kind), matching equality.

Ordering a Field with <, <=, >, or >=:
  Always reject field ordering.
  Raise a syntax error that ordering needs a numeric Expression such as Expression(Field(name), AsNumber()).

_require_nonempty_name(name):
  If name is not a non-empty string, raise a syntax error that Field name must be a non-empty string.

_require_allowed_kind(kind):
  If kind is not in _ALLOWED_KINDS, raise a syntax error that Field kind must be source, analysis, or None.

_reject_field_ordering(field_name):
  Raise a syntax error that Field ordering is not supported and a numeric Expression should be used instead.
