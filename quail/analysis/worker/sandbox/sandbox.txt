There are approved string methods, Quail methods, data attributes, and a
container-mutation deny list matching api.md.

ValidatedQuailProgram remembers:
  tree
  assigned_names
  deleted_names

validate_quail_code(code):
  Require code is a string and parse it as a module.
  Walk the AST and reject imports, defs, classes, lambdas, try/raise,
  f-strings, comprehensions, is/is not, dangerous names, private attrs,
  Entry construction, and item/attr assignment.
  Track top-level Name Store as assigned_names and Name Del as deleted_names.
  Reject reserved binding names on assign/del.
  Limit attribute loads and method calls to the approved lists.
  Reject container mutation methods, dict iterators, .get, and re.compile.
  Give back ValidatedQuailProgram on success.
