MAX_PRINT_BYTES caps the print buffer.

PrintBuffer remembers chunks and byte_count.
write appends text or raises if the byte limit is exceeded.
text gives back the joined buffer.

HostEndpoint sends encode_api_call messages and decodes api_result payloads.
call allocates contiguous ids.
On api_result failure, raise rehydrate_quail_error(exception_type, message,
  repair_hint).

set_host_call / reset_host_call:
  Context var used by Entry.value and Entry.fields RPC helpers.

entry_value_rpc / entry_fields_rpc:
  Require an active host callback and forward entry_value / entry_fields.

build_namespace(endpoint, prints):
  Give back the injected quail_exec namespace with RPC wrappers and safe builtins
  (including bytes).

host_call_from_endpoint(endpoint):
  Adapt HostEndpoint.call for the Entry context var.
