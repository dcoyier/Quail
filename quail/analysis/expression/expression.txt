Expression is an immutable field plus operation pipeline.

An Expression remembers:
  root Field
  operations tuple

To create an Expression from input and zero or more operations:
  If input is a Field, root is that Field and pipeline is the operations.
  If input is an Expression, root is input.root and pipeline is input.operations plus the new operations.
  Otherwise raise that input must be a Field or Expression.
  Require every pipeline item is an Operation.
  Drop leading Value() ops (identity). An empty pipeline is identity: the field value.
  Validate the operation pipeline.
  Remember root and operations.

input property:
  Give back root.
  Matches the public API idea of expression input.

to_record:
  Give back kind Expression, root record, and operation records.

Comparing an Expression with <, <=, >, >=, ==, or !=:
  Build a Predicate with that operator and the other value.

Adding an Expression to another Expression or Ranking:
  Treat as Ranking(expression=self) + other.

Multiplying an Expression by a weight on the right:
  Treat as Ranking(expression=self) * weight.

Multiplying with weight on the left:
  Raise that ranking weight must be on the right.

Using an Expression as a Python bool:
  Raise that Expressions must be compared explicitly.

Iterating an Expression:
  Raise that Expression values are symbolic and must not be iterated.
