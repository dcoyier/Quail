There are binding kinds literal, literal_v2, field, unit, operation,
expression, predicate, ranking, group_expr, entry, and result_list.
There is a reserved-name set matching the injected quail_exec namespace.
There is a max binding name byte budget of 128, a max depth of 64, and a
max item budget of 100_000.

EncodedBinding remembers:
  value_kind
  value

BindingEncodingError is a QuailSyntaxError naming a variable that cannot
persist.

encode_binding_value(value):
  Encode Field, Unit, Operation, Expression, Predicate, Ranking, GroupExpr,
  and Entry via to_record.
  Encode None, bool, int, float, and str as literal.
  Encode plain list and dict as literal_v2 when fully JSON-like.
  Encode lists with symbolic items as result_list plain_list.
  Raise for tuples, sets, callables, re, cycles, and non-finite floats.

decode_binding_value(value_kind, value):
  Rehydrate one binding through the matching decoder.

encode_namespace(namespace, reserved_names default RESERVED_NAMES):
  Skip reserved names and __builtins__.
  Encode each remaining identifier.
  Raise BindingEncodingError when a value cannot persist.

decode_namespace(bindings):
  Require EncodedBinding values and give back a live namespace map.

canonical_binding_bytes(binding):
  Round-trip encode then give back deterministic UTF-8 JSON bytes.

require_namespace_name(name):
  Require a non-keyword identifier under the byte budget.

binding_to_payload / binding_from_payload / bindings_to_payload /
bindings_from_payload:
  Convert EncodedBinding maps for the worker NDJSON protocol.
