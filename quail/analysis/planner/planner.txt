RetrievePlan remembers unit, group, limit, order, and ranking.

CountPlan remembers unit (a Unit) and group.

CreateFieldPlan remembers a Field with kind analysis.

TagPlan remembers group (GroupExpr or Entry tuple), field, and value.

UntagPlan remembers group, field, and optional value.

plan_retrieve(unit, group, limit, order, rank):
  Default group to G0 and rank to empty Ranking.
  Require unit is Unit or Expression.
  Require group is GroupExpr or a list of Entry (wrap the list as an entries members group).
  Require positive limit and order in top, middle, bottom.
  If rank is an Expression, wrap Ranking(expression=rank).
  Require rank is then a Ranking.
  Require unit and group scopes match.
  Reject ranking for fields and values units.
  Give back a RetrievePlan.

plan_count(unit, group):
  Reject an Expression unit.
  Same remaining unit and group rules as retrieve.
  Give back a CountPlan.

plan_create_field(field):
  Accept a string name or Field and normalize to analysis Field.
  Strip leading and trailing whitespace from the name.
  Raise QuailSyntaxError when the stripped name is empty.
  Raise QuailSyntaxError when the name is id.
  Give back a CreateFieldPlan.

plan_tag(group, field, value):
  Require Field and non-None value.
  Reject nested None inside the value.
  Require entry-scoped GroupExpr or list of Entry.
  Give back a TagPlan.

plan_untag(group, field, value default None):
  Same group and field rules as tag.
  When value is provided, reject nested None inside it.
  Give back an UntagPlan.

require_tag_value(value, label default "Tag value"):
  Walk lists and dicts.
  Raise QuailSyntaxError on None, cycles, non-string keys, non-finite floats,
  or unsupported types.
