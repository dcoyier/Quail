There is a private secret called _ENTRY_TOKEN.
Only make_entry and the engine may use it.

Entry is an immutable handle for one dataset row.
It is issued by retrieve, not by user code.

An Entry remembers:
  id
  dataset_id (default empty)
  dataset_version_id (default empty)
  dataset (default empty)

To create an Entry from entry_id and optional dataset fields, with token:
  First require that the host token is valid.
  Then require that the entry id is a non-empty string.
  Then remember id as entry_id.
  Then remember dataset_id, dataset_version_id, and dataset.

to_record:
  Give back a plain dictionary of those four remembered values.
  Used for debugging or later serialization.

value(field, default):
  Meant to give one cell value from this row.
  Not wired yet, so raise a runtime error that value is only available during quail_exec evaluation.

fields:
  Meant to give the list of Field columns present on this row.
  Not wired yet, so raise a runtime error that fields are only available during quail_exec evaluation.

make_entry(entry_id, optional dataset fields):
  For the host, tests, and engine — not for agent scripts.
  Create an Entry using the private _ENTRY_TOKEN so construction is allowed.

_require_host_token(token):
  If token is not _ENTRY_TOKEN, raise a syntax error that Entry handles are created by Quail, not user code.

_require_nonempty_entry_id(entry_id):
  If entry_id is not a non-empty string, raise a syntax error that Entry id must be a non-empty string.
