PrintBuffer collects print text for a host-side run.
It remembers chunks.
write appends sep-joined values plus end.
text gives back the joined buffer.

ExecOutcome remembers printed_output and state_revision after a successful run.

dispatch_call(engine, method, args, kwargs):
  Plan the named facade method then evaluate it on the engine.
  Supports retrieve, count, create_field, tag, untag, entry_value, entry_fields.
  This shape is what the worker RPC calls.

run_analysis(db, session_id, dataset_id, expected_revision, driver,
             similarity/lexical default None):
  Resolve and ensure scope.
  Build a QueryEngine (with optional SimilarityService and LexicalService) and
  PrintBuffer.
  Run the driver.
  On success, commit_overlay with staged mutations.
  Give back ExecOutcome.
  If the driver raises, do not commit.

exec_script(db, session_id, dataset_id, expected_revision, code,
            similarity/lexical default None):
  Resolve and ensure scope.
  Build a QueryEngine with optional SimilarityService and LexicalService.
  Load session bindings and spawn the worker with the code plus bindings.
  Answer api_call via dispatch_call.
  On worker success, commit_overlay with mutations, changed bindings, and
  binding deletes; give back ExecOutcome with worker printed_output.
  If the worker fails, do not commit.
