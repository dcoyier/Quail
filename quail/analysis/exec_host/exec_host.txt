PrintBuffer collects print text for a host-side run.
It remembers chunks.
write appends sep-joined values plus end.
text gives back the joined buffer.

ExecOutcome remembers printed_output and state_revision after a successful run.

dispatch_call(engine, method, args, kwargs):
  Plan the named facade method then evaluate it on the engine.
  Supports retrieve, count, create_field, tag, untag, entry_value, entry_fields.
  This shape is what the worker RPC calls.

run_analysis(db, session_id, dataset_id, expected_revision, driver,
             similarity/lexical default None):
  Resolve and ensure scope.
  Build a QueryEngine (with optional SimilarityService and LexicalService) and
  PrintBuffer.
  Run the driver.
  On success, commit_overlay with staged mutations.
  Give back ExecOutcome.
  If the driver raises, do not commit.

exec_script(db, session_id, dataset_id, expected_revision, code,
            similarity/lexical default None, search_runtime default None,
            time_window default standard, limits default None,
            cancel_event default None):
  Resolve and ensure scope.
  Resolve ExecLimits from limits or time_window.
  Acquire session lock (fail session_busy if overlapping), then exec slot
  (fail server_busy if full).
  When search_runtime is set, checkout a SearchDb and bind per-exec Lexical
  and Similarity services; otherwise use the passed similarity/lexical.
  Install interrupt_connections_on_cancel on core (and search) connections.
  Load session bindings.
  Build QueryEngine, then validate_encoded_bindings on restored bindings
  (structural only — skip Field kind vs catalog). Bindings are session-global;
  kinds are dataset-specific. A stale kind must not block exec: using the Field
  still fails in resolve_field, and del recovers.
  Spawn the worker with cancel_event so wall/memory also cancel host Turso work.
  Answer api_call via dispatch_call with cancel checks before and after each
  call (not mid-call). Residual timeout exposure is non-DB host compute inside
  one dispatch_call; DB work is best-effort interrupted via the connections.
  On worker success, validate_encoded_bindings on changed_bindings before
  commit_overlay; on mismatch raise and do not commit.
  Always release SearchDb and locks.
  If the worker fails, do not commit.
