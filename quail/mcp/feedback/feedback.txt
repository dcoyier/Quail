There is a private message size cap of 16 KiB (UTF-8) and a private feedback
file quota of 64 MiB.

append_feedback(path, workspace_id, message, category default None, session_id default None, dataset_id default None):
  Require a non-empty message and workspace_id.
  Raise ValueError when the message exceeds the 16 KiB UTF-8 byte cap.
  Optional category, session_id, and dataset_id must be strings or None.
  Empty optional strings become None.
  Build one JSON object with timestamp, workspace_id, message, and the optional fields.
  Ensure the parent directory exists.
  Raise ValueError when the feedback file already meets or exceeds the 64 MiB quota.
  Append the object as one JSON line.
