There is PROTOCOL_VERSION, the 2026-07-28 MCP revision Quail serves.
There are handshake JSON-RPC methods initialize and notifications/initialized.

attach_modern_http(server):
  Wrap MCPServer.streamable_http_app so every HTTP app is stateless_http,
  has no event_store, and runs _HandshakeRejectMiddleware on the MCP path
  (streamable_http_path, default /mcp). Handshake-era requests cannot be
  represented on a Quail-built server.

_HandshakeRejectMiddleware:
  Pure ASGI wrapper so SSE bodies are not buffered.
  On POST to the MCP path, buffer the request body, replay it, and if the
  request is handshake-era give back JSON-RPC -32022 naming supported
  PROTOCOL_VERSION. Otherwise call the inner app.

_buffer_http_body / _header:
  Read the POST body once, replay it, then any leftover ASGI message, and
  look up a header on the ASGI scope.

_handshake_rejection(header_version, body):
  If method is initialize or notifications/initialized, reject (include
  params.protocolVersion when present).
  If mcp-protocol-version is PROTOCOL_VERSION, allow.
  If mcp-protocol-version is any other value, reject.
  If there is no method, allow (empty or non-RPC bodies fall through).
  If params._meta carries PROTOCOL_VERSION under the reserved key, allow.
  Otherwise reject: JSON-RPC without a modern envelope is handshake-era.

_jsonrpc_parts / _jsonrpc_id / _has_modern_envelope / _unsupported_response:
  Classify the POST body and build the -32022 JSON response. JSON-RPC id
  is string, int, or null.
