There is a default workspace id called local.

McpContext is the process-fixed unrestricted MCP context.
McpContext remembers:
  db_path
  workspace_id
  feedback_path
  api_docs_path
  search_runtime (optional SearchRuntime with pooled SearchDb)
  include_dataset_docs_in_setup (default false)
Tools open CoreDb per call from db_path; exec checks out SearchDb from the pool.
