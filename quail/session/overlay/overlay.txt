resolve_scope(db, session_id, dataset_id, version_id default None):
  Require an active session.
  If version_id is missing, use the dataset active_version_id.
  Require that version exists and is ready.
  Give back a Scope.

ensure_scope(db, scope):
  Require an active session matching the scope.
  Insert the analysis scope row if missing.
  Commit.

analysis_fields(db, scope):
  Give back AnalysisField rows in position order.

analysis_values(db, scope, field, entry_ids default None):
  Require a known analysis field.
  If entry_ids is missing, load the whole field (no IN list) in source entry order.
  If entry_ids is set, read in chunks of 500 ids.
  Give back one decoded value or None per entry id.

catalog_fields(db, scope):
  Give back source CatalogFields then analysis CatalogFields.

commit_overlay(db, scope, expected_revision, mutations, bindings, binding_deletes):
  Begin an immediate transaction.
  Require an active session whose state_revision matches expected_revision.
  Ensure the scope row exists.
  Apply FieldCreate, ValueWrite, and ValueDelete in order.
  Reject analysis names that collide with source fields.
  Upsert EncodedBinding rows and delete bindings when provided.
  If anything changed, bump state_revision.
  Always refresh last_used_at.
  Commit and give back the new revision.
  On failure, roll back.

load_bindings(db, session_id):
  Give back every session binding as EncodedBinding, ordered by name.

Helpers encode values with canonical_json, hash them, bump field and scope
value revisions, and validate entry and field ids.
Binding upserts store value_kind and allow JSON null literal bodies.
