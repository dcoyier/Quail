There are private allowed-key sets for unrestricted and clerk roots, auth, core,
hosting, workspace, dataset, embedding, lexical, providers, user, extension, and
connector tables.

load_config(config_path):
  Require an absolute path.
  Resolve and require the file exists.
  Read UTF-8 text.
  Parse with parse_config using that manifest path.

parse_config(raw_text, manifest_path):
  Require an absolute manifest_path.
  Parse TOML.
  Require [auth].mode unrestricted or clerk.
  Require [core] database and feedback; resolve paths.
  Optional core.search_database; must differ from core.database.
  Require [hosting] bind, port 1..65535, optional max_concurrent_executions
  (default 2, range 1..100), optional public_base_url (http(s) origin; defaults
  from bind/port with IPv6 hosts bracketed; 0.0.0.0 / :: require an explicit
  public_base_url), optional
  allow_public_unrestricted (boolean, default false; unrestricted-only), optional
  allow_insecure_http (boolean, default false; clerk-only), and optional
  include_dataset_docs_in_setup (boolean, default false).
  Optional [providers.ollama] / [providers.openrouter] (api_key must be env:NAME).
  Parse optional [[extensions]] (id + version pins, unique ids).
  If unrestricted: require auth.workspace and optional root [[datasets]]; reject clerk-only keys.
  Unless allow_public_unrestricted is true, require bind and public_base_url host to be
  loopback (127.0.0.1, localhost, or ::1). Reject allow_insecure_http.
  Parse optional root [[connectors]] against pinned extension ids and workspace dataset ids.
  If clerk: require auth.clerk_domain, auth.clerk_authorized_parties (non-empty
  azp/aud party ids), [[workspaces]] with nested datasets, and [[users]];
  reject auth.workspace, root [[datasets]], and allow_public_unrestricted.
  Unless allow_insecure_http is true, require non-loopback public_base_url to be https.
  Parse optional workspaces[].connectors against pinned extension ids and that workspace's
  dataset ids.
  For datasets: optional [datasets.embedding] with provider, model, dimensions > 0, revision,
  and optional fields (non-empty string array of CSV columns to embed; omit = all fields).
  Optional [datasets.lexical] with required fields (non-empty string array of CSV columns
  for Lexical warm; omit the table = all source fields).
  For users: validate memberships, optional default_workspace, optional lock_workspace (requires default).
  When any dataset has embedding: require search_database and the matching provider blocks.
  Give back a QuailConfig.

_parse_extensions(raw):
  Require an array of tables with id and version.
  Reject duplicate ids.
  Give back ExtensionPin tuples.

_parse_connectors(raw, extension_ids, dataset_ids, label_prefix):
  Require an array of tables with id pinned in extensions.
  Optional config table (JSON-shaped) and datasets array of {id} tables in dataset_ids.
  Reject duplicate connector ids and unknown dataset ids.
  Give back ConnectorBinding tuples.
