There are private allowed-key sets for unrestricted and clerk roots, auth, core, hosting, workspace, dataset, and user tables.

load_config(config_path):
  Require an absolute path.
  Resolve and require the file exists.
  Read UTF-8 text.
  Parse with parse_config using that manifest path.

parse_config(raw_text, manifest_path):
  Require an absolute manifest_path.
  Parse TOML.
  Require [auth].mode unrestricted or clerk.
  Require [core] database and feedback; resolve paths.
  Require [hosting] bind and port 1..65535.
  If unrestricted: require auth.workspace and optional root [[datasets]]; reject clerk-only keys.
  If clerk: require auth.clerk_domain, [[workspaces]] with nested datasets, and [[users]]; reject auth.workspace and root [[datasets]].
  For users: validate memberships, optional default_workspace, optional lock_workspace (requires default).
  Give back a QuailConfig.
