AuthMode is unrestricted or clerk.
EmbeddingProviderName is ollama or openrouter.

EmbeddingProfile is the per-dataset Semantic cache identity.
EmbeddingProfile remembers:
  provider
  model
  dimensions
  revision
profile_hash:
  SHA-256 of the canonical JSON of those four fields.

OllamaProvider remembers base_url.
OpenRouterProvider remembers base_url and api_key (env:NAME ref string).
ProvidersConfig remembers optional ollama and openrouter blocks.

SearchWarmConfig remembers embed_batch_size and max_concurrent_embed_requests
for quail process (defaults 32 and 2).

DatasetSpec is one CSV dataset declared in the manifest.
DatasetSpec remembers:
  workspace_id
  dataset_id
  source
  name (optional)
  embedding (optional EmbeddingProfile)

WorkspaceSpec is one workspace and its declared datasets.
WorkspaceSpec remembers:
  workspace_id
  datasets

UserSpec is a TOML allowlisted Clerk user.
UserSpec remembers:
  user_id
  clerk_user_id
  workspaces
  default_workspace (optional)
  lock_workspace

QuailConfig is the resolved slim deployment config for quail run.
QuailConfig remembers:
  manifest_path
  database
  feedback
  auth_mode
  bind
  port
  workspace_id (unrestricted only; None for clerk)
  clerk_domain (clerk only; None for unrestricted)
  workspaces
  users
  datasets (flattened for apply)
  search_database (optional; required when any dataset has embedding)
  providers
  search_warm
  max_concurrent_executions
