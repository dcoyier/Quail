Register connected connector tools, resources, widgets, and HTTP routes on FastMCP.

register_connectors(server, catalog, resolve_workspace):
  Attach tools/resources/widgets/routes. resolve_workspace receives FastMCP
  Context (or None) and returns workspace_id and optional user_id.
  Reject when two different connectors claim the same tool name or resource URI.
  The same connector may expose the same tool/URI across workspaces.
  Tool handlers fail when the tool is not active in that workspace. Required tool
  parameters are bound before optional ones and Context (annotated so FastMCP
  injects it and does not advertise ctx on tools/list).
  After add_tool, publish ToolSpec.input_schema onto the FastMCP tool parameters
  so tools/list shows the real JSON Schema (not the Any signature).
  ToolResult structured_content becomes structuredContent; optional text becomes
  the MCP text content block (not merged into structured content). When text is
  omitted and images are present, content is image-only. Optional images become
  MCP ImageContent blocks after any text block.

Routes mount at /extensions/{extension_id}/{workspace_id}/{path_suffix} for each
RouteSpec. GET only. The handler resolves the workspace-bound provider, calls
handle_route, and streams FileResponse bytes (404 when None).
