There is a limit _MAX_INT_DIGITS set to 4096.

canonical_json(value):
  Normalize value and give back stable JSON text with sorted keys and compact separators.
  Used for hashing and durable source values.

decode_json(text):
  Parse JSON text and normalize it the same way.

value_hash_from_canonical_json(encoded):
  Hash domain quail:value:v1 plus the encoded UTF-8 bytes with SHA-256.
  Give back the hex digest.

dataset_content_hash(entries, fields):
  Hash every behaviorally relevant part of one immutable source version.
  Accept entries as a one-shot iterable so large sources can be hashed while reading.
  Feed SHA-256 the prefix quail:dataset:v1, then a JSON object of ordered entries
  and the field-name list, using canonical_json for each entry and for fields.
  Give back the hex digest.

_normalize_json(value):
  If value is None, a string, or a bool, give it back as-is.
  If value is an int but not a bool, require it is bounded, then give it back.
  If value is a float, require it is finite, then give it back.
  If value is a list or tuple, normalize each item into a list.
  If value is a dict, require string keys and normalize each value.
  Otherwise raise a syntax error that the type is unsupported.
