SourceField is an immutable named source column in one dataset version.
It remembers name and position.

SourceEntry is an immutable row handle in one dataset version.
It remembers id and position.

ActiveVersion is the dataset's active ready version pointer.
It remembers version_id and content_hash.

DatasetRef is the result of an import or dataset lookup.
It remembers:
  workspace_id
  dataset_id
  name
  active_version_id
  version_id
  content_hash

CsvDataset is a parsed UTF-8 CSV ready to import, with no database write yet.
It remembers:
  path
  version_id
  content_hash
  byte_count
  cell_count
  estimated_durable_bytes
  field_names
  entries
