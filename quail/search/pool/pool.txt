SearchDbPool(path, max_size):
  Bounded idle list of SearchDb handles for one search database file.
  checkout(): reuse an idle handle or open a new one while under max_size;
    raise QuailServerBusyError when every slot is checked out.
  release(search): return a handle to the idle list (or close if pool closed).
  close(): close idle handles and refuse new checkouts.
  connection(): context manager that checkout/release.

open_search_pool(path, max_size):
  Resolve the path and give back a SearchDbPool.
