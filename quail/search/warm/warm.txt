WarmReceipt remembers workspace_id, dataset_id, version_id, build_fingerprint
(search-build fingerprint; DB column remains profile_hash), lexical_ready,
embedding_ready, text_count, and warmed_at.

WarmDatasetResult remembers one process summary for a dataset version, including
build_fingerprint.

There is a private search-build schema version constant (bumped when Lexical
or embedding artifact layout changes).
There is a fixed embedding-segment write batch of 1,000 rows.

search_build_fingerprint(lexical_fields, profile):
  SHA-256 of canonical JSON covering schema version, lexical field list
  (null when unrestricted), and embedding profile_hash (null when none).

get_warm_receipt / put_warm_receipt:
  Load or upsert the quail_search_warm row.
  put_warm_receipt takes build_fingerprint and stores it in the profile_hash column.

clear_search_version:
  Drop every per-field Lexical corpus for the version, all vectors, all compact
  embedding field/segment mappings, and the warm receipt.

collect_field_corpora:
  Read source fields for every entry (all fields, or field_names when set).
  Keep non-empty text cells per field.
  Give back field_name -> (entry_id -> segment list).
  Unknown field_names raise QuailRuntimeError (source fields message).

collect_corpus_texts:
  Flatten collect_field_corpora into a flat text list and per-entry segment lists.
  Used by embedding warm.

warm_dataset:
  Optionally clear the version.
  Compute the search-build fingerprint from lexical_fields and profile.
  Collect per-field corpora for Lexical using lexical_fields when set
  (else all fields).
  Write a not-ready warm receipt before Lexical rebuild so a mid-pass failure
  cannot leave lexical_ready over a partial index.
  If an existing receipt had a different fingerprint, delete all vectors and
  compact embedding maps for the version only after that not-ready receipt
  (never while still ready).
  If profile is None, delete the embedding pin and compact embedding maps after
  the not-ready receipt (before Lexical rebuild and the ready receipt).
  For each field, resolve that field's corpus and rebuild with
  warm_entry_segments (plain row writes, then one FTS build).
  Drop any registered field corpora not in this warm set.
  When a profile is set, collect embed texts from profile.fields only
  (or all fields when fields is omitted — never reuse the Lexical text list),
  then embed unique missing texts in batches with at most
  max_concurrent_embed_requests in flight (provider calls only; cache writes
  stay on the main thread).
  Unless clear is set, copy cached vectors for those unique texts from any
  other version of the same workspace and dataset id with the same
  profile_hash and dimensions before embedding misses. --clear skips that copy.
  Replace the compact source-field entry/segment-to-text-hash mappings after
  embeddings succeed.
  Write a ready warm receipt storing the search-build fingerprint.
  Give back WarmDatasetResult.

_delete_embedding_field_maps:
  Delete quail_embedding_segments for the version's field_ids first, then
  delete quail_embedding_fields. Do not rely on CASCADE alone.

_replace_embedding_segments:
  Call _delete_embedding_field_maps for the dataset version.
  Register every embedding source field collected for this warm.
  Give each field registration a compact integer field_id.
  For each field, remember field_id, entry id, segment index, and text_hash.
  Do not copy source text or vector blobs.
  Write mappings in fixed-size batches so process memory does not grow with the
  mapping row count.
  Commit the replacement.

require_warm_ready(search, workspace_id, dataset_id, version_id, profile,
  lexical_fields default None):
  Fail closed when the receipt is missing, Lexical is not ready, search-build
  fingerprint does not match TOML lexical+embedding, embedding readiness
  disagrees, the stored pin hash mismatches the embedding profile_hash, or a
  pin remains when TOML has no embedding.
