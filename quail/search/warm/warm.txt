WarmReceipt remembers workspace_id, dataset_id, version_id, build_fingerprint
(search-build fingerprint; DB column remains profile_hash), lexical_ready,
embedding_ready, text_count, and warmed_at.

WarmDatasetResult remembers one process summary for a dataset version, including
build_fingerprint.

There is a private search-build schema version constant (bumped when Lexical
or embedding artifact layout changes).
There is a private 10,000-row source batch size.
There is a private 32-batch embedding commit group.
There is a private 10,000-row embedding-segment write batch.

search_build_fingerprint(lexical_fields, profile):
  SHA-256 of canonical JSON covering schema version, lexical field list
  (null when unrestricted), and embedding profile_hash (null when none).

get_warm_receipt / put_warm_receipt:
  Load or upsert the quail_search_warm row.
  put_warm_receipt takes build_fingerprint and stores it in the profile_hash column.

clear_search_version:
  Drop every per-field Lexical corpus for the version, all vectors, all compact
  embedding segment mappings, and the warm receipt.

collect_field_corpora:
  Materialize source fields for every entry (all fields, or field_names when set).
  Keep non-empty text cells per field.
  Give back field_name -> (entry_id -> segment list).
  Unknown field_names raise QuailRuntimeError (source fields message).
  Keep this compatibility helper separate from the bounded warm path.

collect_corpus_texts:
  Materialize collect_field_corpora into a flat text list and per-entry segment lists.
  Keep this compatibility helper separate from the bounded warm path.

warm_dataset(..., progress default None):
  Optionally clear the version.
  Compute the search-build fingerprint from lexical_fields and profile.
  If an existing receipt has a different fingerprint, keep vectors only when
  the existing pinned profile_hash still equals the desired embedding profile.
  Delete compact embedding field and segment artifacts so they are rebuilt.
  Write a not-ready warm receipt before field validation or collection so any
  failed re-warm leaves serve fail-closed.
  Validate and select Lexical fields using lexical_fields when set (else all fields).
  For each field, stream source values in bounded entry batches and rebuild with
  warm_entry_segment_batches (plain row writes, then one FTS build).
  Drop any registered field corpora not in this warm set.
  When a profile is set, database-stream distinct texts from profile.fields only
  (or all fields when fields is omitted).
  Embed missing texts with bounded provider requests, vectors, and cache transactions.
  After embeddings succeed, stream each selected source field again and replace
  its compact entry/segment-to-text-hash mappings in bounded transactions.
  Without an embedding profile, database-count distinct Lexical texts.
  Report field and embedding progress when given a progress callback.
  Write a ready warm receipt storing the search-build fingerprint.
  Give back WarmDatasetResult.

_selected_source_fields:
  Give back all source field names or the requested subset.
  Raise QuailRuntimeError naming unknown fields.

_lexical_entry_batches:
  Stream one field in bounded batches.
  Keep only nonempty strings and shape them as entry segment dictionaries.

_replace_embedding_segments:
  Delete prior field registrations and mappings for the dataset version.
  Register every selected embedding source field, including empty fields.
  Give each field registration a compact integer field_id.
  Stream one source field at a time in 10,000-row batches.
  For each nonempty text, remember field_id, entry id, segment index zero, and
  text_hash without copying source text or vector blobs.
  Commit and checkpoint each bounded mapping group.
  Report the mapped segment count for each field.

_warm_embeddings:
  Stream unique texts and check the version-scoped vector cache one at a time.
  Keep at most max_concurrent_embed_requests provider batches in flight.
  Accumulate at most 32 completed batches, then write them in one immediate transaction.
  Checkpoint after each vector group and report committed-batch progress.
  Give back submitted batch count and unique text count.

_emit_progress:
  Send a message when a progress callback is present.

require_warm_ready(search, workspace_id, dataset_id, version_id, profile,
  lexical_fields default None):
  Fail closed when the receipt is missing, Lexical is not ready, search-build
  fingerprint does not match TOML lexical+embedding, embedding readiness
  disagrees, or the stored pin hash mismatches the embedding profile_hash.
