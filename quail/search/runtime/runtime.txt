SearchRuntime holds path, ProvidersConfig, and a SearchDbPool.
bind_services(search): build SimilarityService + LexicalService on that SearchDb.

SearchServices holds one SearchDb plus SimilarityService and LexicalService
(single-threaded warm helpers / tests).

search_runtime_from_config(config):
  If core.search_database is unset, give back None.
  Otherwise build a SearchRuntime with pool size = max_concurrent_executions.

search_services_from_config(config):
  If core.search_database is unset, give back None.
  Otherwise open one SearchDb and wrap both services (not for concurrent MCP).

similarity_from_config / lexical_from_config:
  Convenience wrappers that return one service (or None).
