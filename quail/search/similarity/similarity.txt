SimilarityService remembers a SearchDb, ProvidersConfig, and optional embedder_factory.

semantic_score(...):
  Delegate to semantic_scores_for_entries for a single synthetic entry.

semantic_scores_for_entries(workspace_id, dataset_id, version_id, corpus_by_entry,
                            query_record, input_aggregation, target_aggregation):
  Require a pinned embedding profile for the version.
  If none, raise QuailRuntimeError with repair_hint to add [datasets.embedding]
    and re-run quail process, then retry the whole exec.
  Use the stored pin profile_hash for vector cache keys (not a recomputed hash
    from get_embedding_pin, which omits optional fields).
  If the stored profile_hash is missing, raise QuailRuntimeError with
    repair_hint to re-run quail process to refresh the embedding pin, then retry.
  Resolve corpus and LiteralText / LiteralTextList query texts.
  Reject unresolved EntryGroup / EntryList (QueryEngine must resolve those first).
  Embed missing texts once through the provider and cache unit-vector blobs.
  If a provider vector length does not match the pin dimensions, raise
  QuailRuntimeError with repair_hint to align datasets.embedding.dimensions,
  re-run quail process, and retry the whole exec.
  Stage corpus segment hashes in a TEMP table, join to the vector cache, and score
  with Turso -vector_distance_dot (exact unit cosine).
  Raise QuailRuntimeError when a cosine is null, non-numeric, or non-finite
  (do not map those to 0.0).
  Aggregate target then input with total or avg.
  Give back entry_id -> score | None.
  Raise QuailRuntimeError with repair_hint when search or provider wiring fails.

semantic_scores_for_source_entries(workspace_id, dataset_id, version_id, entry_ids,
                                   source_field, all_entries, query_record,
                                   input_aggregation, target_aggregation):
  Require the pinned profile and stored profile_hash.
  If source_field was not registered during embedding warm, give back None so the
  caller can use dynamic corpus scoring.
  Embed and cache only missing target text.
  Score registered source segments directly from the search database.
  Omit candidate-id filtering when all_entries is true.
  Aggregate target scores, then segment scores per entry.
  Give back every requested entry id, using None for entries without segments.

_profile_for:
  Require and give back the pinned EmbeddingProfile and stored profile_hash.

_ensure_texts:
  Find uncached unique texts.
  Embed missing texts once and cache unit-vector blobs.
  Require the configured dimensions.

_require_blob:
  Give back one cached vector blob.
  Raise when the blob is still absent after embedding.

_pairwise_cosine_batches(segment_sql, extra_parameters, target_blobs):
  Score exact cosine with Turso -vector_distance_dot in batches of
  _SCORE_TARGET_BATCH targets.
  Bind each batch, then extra_parameters, into one SELECT of entry_id,
  segment_index, and one cosine column per target in the batch.
  segment_sql is the FROM/JOIN/WHERE that aliases segments as s and vectors as v.
  Accumulate finite pairwise scores per (entry_id, segment_index).
  Raise when a cosine is null, non-numeric, or non-finite.
  Give back those pairwise lists (no target or input aggregation).

_score_segments_turso:
  Rebuild the request-local segment stage table for dynamic corpus values.
  Ask _pairwise_cosine_batches to join staged text hashes to cached vectors.
  Aggregate target scores per segment.

_score_source_entries_turso:
  Join the field's persistent entry/segment mappings directly to cached vectors.
  For a subset, restrict entry ids through json_each.
  For the full corpus, do not serialize or filter candidate ids.
  Ask _pairwise_cosine_batches to score those rows.
  Then aggregate targets per segment, then input segments per entry.

_client_for:
  Reuse one embedding client per profile_hash.
  Build it on first use and translate ProviderError to QuailRuntimeError.

_corpus_texts:
  Give back text segments for a dynamic corpus value.

_target_texts:
  Give back literal query text targets.

_aggregate:
  Give back total or average finite scores.

_finite_score:
  Require a finite number or raise. Do not map null/non-finite cosine to 0.0.
