SearchDb is a process-local handle to one rebuildable search database file.
It remembers path and connection.

close / context manager:
  Close the connection once.

open_search_db(path):
  Resolve path, require a file name, create parent directories.
  Connect with turso (experimental_features=index_method for native FTS),
  enable foreign keys, WAL, full synchronous, and busy_timeout=5000.
  Apply search migrations.
  Give back a SearchDb.
