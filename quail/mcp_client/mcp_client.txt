There is a default MCP URL called DEFAULT_URL: http://127.0.0.1:8000/mcp.
There is PROTOCOL_VERSION 2026-07-28, the MCP revision this client speaks.
There is a private HTTP read timeout of 300 seconds, used for Client connect
and for each tools/call round.

main(optional argv):
  Parse list or call.
  Resolve --url with _mcp_url.
  If argparse raises SystemExit, give back that integer code, or 2 if the code is not an int.
  For list, call list_tools with the URL, print JSON, give back 0.
  For call, load_arguments, call_tool, print the tool result JSON object.
  That object is structured_content when it is a JSON object; otherwise a
  JSON object parsed from text content blocks (or {"text": ...} when the
  text is not a JSON object). When is_error is true and there is no
  diagnostic object, print {execution_id: null, diagnostic} from the text
  instead of a {"text": ...} wrap. Never print isError or content blocks.
  Give back 1 when the tool result is_error is true.
  Give back 2 for bad usage, bad JSON arguments, or an unreadable @path file.
  Give back 1 for other connection or runtime failures.
  Catch ValueError only from load_arguments (usage); other failures use the generic handler.
  For connection failures, unwrap ExceptionGroup/TaskGroup and print the inner
  error, not "unhandled errors in a TaskGroup".
  Write diagnostics to stderr; write only JSON to stdout.

_mcp_url(args):
  Prefer --url after the subcommand, then --url before it, then DEFAULT_URL.

_client(url):
  Give back mcp.Client for url at PROTOCOL_VERSION with the private read timeout.

_client_error_message(error):
  Walk ExceptionGroup to the first leaf. If the text is empty or a TaskGroup
  wrapper, use __cause__ / __context__. Give back that string.

load_arguments(spec):
  If spec is "-", read stdin.
  If spec starts with "@", expanduser that file path and read it.
  If that file cannot be read, raise ValueError.
  Otherwise treat spec as inline JSON text.
  Empty JSON input means {}.
  Require a JSON object (or null treated as {}).
  If JSON is invalid or not an object, raise ValueError.

list_tools(url):
  Open a 2026-07-28 mcp.Client against url with the private read timeout.
  List tools.
  Give back a mapping with tools: name, description, inputSchema for each tool
  (camelCase keys for the operator stdout contract).

call_tool(url, name, optional arguments):
  Open a 2026-07-28 mcp.Client against url with the private read timeout.
  Call the named tool with arguments (default {}).
  Pass the same read timeout on the call.
  Give back the MCP CallToolResult.

_build_parser:
  Build argparse for "python -m quail.mcp_client".
  Optional --url on the parent parser (before the subcommand) and again on
  list/call (after the subcommand).
  Subcommand call takes tool_name and arguments.

_stdout_packet(result):
  If structured_content is a JSON object, give that mapping back.
  Otherwise start from _text_content_packet of the content blocks.
  If is_error is true and that mapping has no diagnostic, give back
  {execution_id: null, diagnostic} with QuailSyntaxError / quail_syntax_error
  and the text as message.

_text_content_packet(content):
  Join non-empty text blocks with a newline, then strip.
  If there is no text, give back {}.
  If the stripped text is a JSON object, give that mapping back.
  Otherwise give back {"text": the raw text}.

_print_json(payload):
  Write indented JSON with sorted keys plus a trailing newline to stdout.
