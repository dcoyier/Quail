apply_config(config):
  Require each dataset source file exists.
  Open the core database.
  When search_database is set, open the search database.
  Ensure each workspace exists.
  Import each declared CSV and activate it.
  When a dataset declares embedding, pin that profile to the imported version_id.
  Close the search database.
  On failure, close the core database and raise.
  Give back the open CoreDb.
