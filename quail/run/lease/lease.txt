acquire_deployment_lease(config):
  Build lock file paths beside core.database and, when set, core.search_database
  (each path name plus ".quail.lock").
  Sort the unique lock paths and take exclusive non-blocking fcntl.flock on each
  in that order (POSIX local filesystems only).
  If any flock is busy, raise QuailRuntimeError naming the holder PID when the
  lock file recorded one, and tell the operator that process and run must not
  share the same core/search databases.
  After a successful flock, write this process PID into the lock file.

_read_holder_pid(lock_path):
  Give back the integer PID recorded in the lock file, or None.

_write_holder_pid(handle):
  Replace the lock file contents with this process PID.
  Used by process_config, serve, and apply_config.
  Yield the lock paths for the with-block lifetime, then unlock and close.
