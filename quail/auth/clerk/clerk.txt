AllowlistedPrincipal remembers the resolved TOML user and clerk_user_id.

TokenVerifier.verify(token):
  Give back the Clerk user id (sub).

ClerkJwtVerifier(clerk_domain):
  Derive issuer, JWKS URL, and OAuth userinfo URL from the Clerk domain.
  verify(token): try RS256 JWT (require exp/iat/sub); on failure, GET /oauth/userinfo
  with the bearer and read sub/user_id.
  On failure, raise UnauthorizedError.

StaticTokenVerifier(tokens):
  Test helper mapping exact bearer strings to clerk user ids.

resolve_allowlisted_user(users, clerk_user_id):
  Give back the matching UserSpec, or raise ForbiddenError.

authenticate_bearer(authorization, verifier, users):
  Require Bearer token.
  Verify and resolve allowlisted user.
  Give back AllowlistedPrincipal.
