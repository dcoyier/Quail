OpenRouterEmbedder POSTs to {base_url}/embeddings with Bearer auth,
model, input texts, and dimensions.

Privacy: every embed_texts call sends the full input strings to the remote
OpenRouter API (off-host). Prefer Ollama when corpus text must stay local.

embed_texts(texts):
  Give back one float vector per input text in request order (data entries may
  carry an index).
  HTTP, JSON, vector-shape, and dimension checks come from the shared
  providers wire helpers (post_json, require_vector); all raise ProviderError.
  Raise ProviderError when the response size does not match the request, an
  index is out of range, or the response is incomplete.
